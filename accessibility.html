Accessibility Statement

Last updated: July 14, 2026

I want this website to be usable by everyone, including people with disabilities. The site aims to conform to WCAG 2.1 Level AA (aligned with Israeli Standard 5568).

What's in place

  • Full keyboard navigation with visible focus indicators.
  • Semantic headings, landmarks, and labels for all form fields.
  • Alternative text for meaningful images.
  • Sufficient color contrast for text.
  • Responsive layout that supports browser zoom up to 200%.

Found an issue?

If anything on this site is hard to use with assistive technology, please tell me and I'll fix it promptly: hadarsap@gmail.com.
